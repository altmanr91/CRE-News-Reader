PTM Lands $125M Financing for St. Pete Multifamily Community

LOAN

Connect CRE — Tue, 29 Sep 2026 14:32:26 +0000

SUMMARY

PTM Partners secured a $125 million construction loan from GID for EDGE Collective II, a 330-unit multifamily high-rise with retail space in St. Petersburg's EDGE District. Berkadia arranged the three-year, floating-rate financing for the Class AA project. This second phase builds upon the success of the initial phase, which included a hotel and other mixed-use components.

DATA POINTS

Property Type: multifamily

Property Name: EDGE Collective II

Units: 330

Loan Amount: $125.0M

Loan Per Unit: $378,788/unit (calculated)

Notable Features: Class AA multifamily high-rise with ground-floor retail.

Project Notes: This is Phase II of the EDGE Collective development.

COMPANIES/PEOPLE

LENDER: GID

SPONSOR PIPELINE
